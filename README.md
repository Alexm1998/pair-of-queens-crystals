# Pair of Queens Crystals - website preview

A static preview of a showcase website for Pair of Queens Crystals.
Live preview: https://preview.gaysgobble.com

## What this is

- Plain HTML, CSS and JavaScript in `index.html` - no build step, no dependencies.
- 15 specimen entries live in the inline `specimens` array in `index.html`. `specimens.json` is a reference copy; keep both the same when editing.
- `assets/studio/` holds 15 AI-assisted studio edits; `assets/originals/` and the other `.webp` files in `assets/` hold the original photographs. Each specimen lets visitors switch to its original photo.
- Fonts: P052 (URW++) and Open Sans - see `FONT-NOTICES.txt`.

## Hosting

Served by GitHub Pages from the `main` branch. `CNAME` points the site at preview.gaysgobble.com. The page carries a `noindex` tag so search engines leave the preview alone.

## Notes

- Studio views are design visualisations, not evidence of the exact sale item. Use accurate photographs or video of the actual specimens for a final sales catalogue.
- Private pieces are not for sale. All other availability and prices must be confirmed with the owner; nothing here is a live stock list.
- Photography remains with its owner.
